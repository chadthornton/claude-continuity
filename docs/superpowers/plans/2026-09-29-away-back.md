# /away and /back Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/away` hands this session's mid-stream task to a Claude Code cloud session; `/back` parks it and fast-forwards its commits into the same local worktree.

**Architecture:** One bash script, `skills/away/away`, with subcommands `launch`, `park` and `land`, holds all the git and CLI mechanics and is tested against real git with a fake `claude`. Two thin skills, `skills/away/SKILL.md` and `skills/back/SKILL.md`, hold the judgment: writing the brief, reading the board, briefing the user. `continuity-save` and the hooks learn to leave `.continuity/away.md` alone, so the brief travels only on the feature branch.

**Tech Stack:** bash (macOS `/bin/bash` 3.2 compatible), git ≥ 2.23, BSD `script(1)`, Claude Code CLI ≥ 2.1.285, Python 3 stdlib for tests.

**Spec:** `docs/superpowers/specs/2026-09-29-away-back-design.md`

## Global Constraints

- Code never reaches the default branch through `/away` or `/back`: `launch` branches off the default branch before committing.
- `.continuity/away.md` never lands on `origin/<default>`: `continuity-save` and both hooks exclude it, the same way they exclude `.continuity/last-activity.txt`.
- Exit codes: 0 ok · 1 launch/park/push failed · 3 not usable here · 4 not parked yet · 5 diverged. The meaning of 1, 2 and 3 matches `continuity-save`'s exit codes.
- Launch prompt, verbatim: `Read .continuity/away.md and follow it exactly.`
- Park message, verbatim: `Stop at the next clean point: commit your work, rewrite <status> and <next> in .continuity/away.md, then make a final commit titled "away: parked" and push.`
- Parked tip subject, verbatim: `away: parked`.
- Test seams: `AWAY_CLAUDE` (claude binary), `AWAY_ALLOW_ANY_ORIGIN=1` (skip the github.com check for local bare remotes).
- `/away` asks zero questions. `/back` asks exactly one, and only on exit 4: **Take what's there now / Keep waiting**.
- Every plugin feature change gets a one-line CHANGELOG entry under `## [Unreleased]` (Keep a Changelog: Added/Changed/Fixed).

## Review Focus

1. **Branch names containing `/`** (`feature/x`): launch must push and land them like any other branch. Test in Task 2.
2. **Task text with quotes** in `-m` (`fix "quoted" thing`): the commit message must keep it intact. Test in Task 2.
3. **Several `claude/*` branches descend from the base** (the cloud pushed twice, or a retry): land picks the newest by committer date, not the first alphabetically. Test in Task 4.
4. **`/back` run twice**: the second run finds the `claude/` branch deleted and `away: parked` already in local history. It should say `ALREADY LANDED` and exit 0, not time out. Test in Task 4.
5. **Branch push rejected at launch** (the remote branch moved): launch must stop with exit 1 before starting any cloud session, so no marker points at a session that has the wrong base. Test in Task 2.

- [ ] **Step 3: Implement `skills/away/away` with `launch`.** Create the file:

```bash
#!/bin/bash
# away — hand this checkout's work to a Claude Code cloud session, and take it back.
#
#   away launch [-m "<task>"]                          commit + push this branch, start a cloud session
#   away park <session-id>                             ask that session to stop at a clean point
#   away land <base-sha> [--timeout S] [--interval S] [--take]
#                                                      fast-forward to the cloud's parked claude/* branch
#
# The cloud session clones this branch but can only push to a harness-named
# claude/<slug> branch cut from the same commit, so `land` finds it by ancestry.
# .continuity/away.md is the brief both sides read; continuity-save never lands it.
#
# Exit codes: 0 ok · 1 launch/park/push failed · 3 not usable here · 4 not parked yet · 5 diverged
# Test seams: AWAY_CLAUDE (claude binary), AWAY_ALLOW_ANY_ORIGIN=1 (skip the github.com check)

set -u
CLAUDE_BIN="${AWAY_CLAUDE:-claude}"
PROMPT='Read .continuity/away.md and follow it exactly.'
PARK_MSG='Stop at the next clean point: commit your work, rewrite <status> and <next> in .continuity/away.md, then make a final commit titled "away: parked" and push.'

die() { echo "$2"; exit "$1"; }

to_root() {
  git rev-parse --is-inside-work-tree >/dev/null 2>&1 || die 3 "SKIP: not a git repository"
  cd "$(git rev-parse --show-toplevel)" || exit 3
}

default_branch() {
  local d
  d=$(git symbolic-ref --short -q refs/remotes/origin/HEAD) && { echo "${d#origin/}"; return; }
  for d in main master; do
    git show-ref -q --verify "refs/remotes/origin/$d" && { echo "$d"; return; }
  done
}

cmd_launch() {
  local task="work in progress" o
  OPTIND=1
  while getopts "m:" o; do
    case $o in m) task="$OPTARG" ;; *) die 3 "usage: away launch [-m task]" ;; esac
  done
  to_root
  local url; url=$(git remote get-url origin 2>/dev/null) || die 3 "SKIP: no origin remote — the cloud clones from GitHub"
  case "$url" in
    *github.com[:/]*) ;;
    *) [ -n "${AWAY_ALLOW_ANY_ORIGIN:-}" ] || die 3 "SKIP: origin is not on github.com ($url) — a cloud session couldn't push its work back" ;;
  esac
  [ -f .continuity/away.md ] || die 3 "SKIP: write .continuity/away.md first"
  command -v script >/dev/null || die 3 "SKIP: script(1) not found — needed to start a cloud session from a script"

  git fetch -q origin 2>/dev/null
  local br d; br=$(git symbolic-ref --short -q HEAD) || die 3 "SKIP: detached HEAD — switch to a branch first"
  d=$(default_branch)
  if [ "$br" = "$d" ]; then
    br="away-$(date +%Y%m%d-%H%M)"
    git switch -q -c "$br" || die 1 "FAILED: could not create branch $br"
  fi

  # Code and the brief go in the WIP commit; other .continuity/ edits are left
  # for continuity-save, so they can still land on the default branch.
  git add -A -- . ':(exclude).continuity' && git add -f -- .continuity/away.md
  if ! git diff --cached --quiet; then
    git commit -q -m "wip(away): $task" || die 1 "FAILED: git commit"
  fi
  git push -q -u origin "$br" 2>/dev/null || die 1 "FAILED: push of $br was rejected — nothing launched. Pull or rebase, then /away again."
  local base; base=$(git rev-parse HEAD)

  # Starting a cloud session is interactive-only (`-p --cloud` is refused), so
  # give it a pseudo-terminal and read the session ID from what it prints.
  local log; log=$(mktemp)
  script -q "$log" "$CLAUDE_BIN" --cloud "$PROMPT" </dev/null >/dev/null 2>&1
  local clean id view esc; esc=$(printf '\033')   # BSD sed has no \x1b
  clean=$(LC_ALL=C sed -e "s/${esc}\[[0-9;?]*[a-zA-Z]//g" "$log" | tr '\r' '\n')
  rm -f "$log"
  id=$(printf '%s\n' "$clean" | grep -Eo 'session_[A-Za-z0-9]+' | head -1)
  view=$(printf '%s\n' "$clean" | grep -Eo 'https://claude\.ai/code/session_[A-Za-z0-9]+' | head -1)
  if [ -z "$id" ]; then
    echo "FAILED: no cloud session started ($br is pushed; nothing else changed). CLI output:"
    printf '%s\n' "$clean" | grep -v '^[[:space:]]*$' | tail -15 | sed 's/^/  /'
    exit 1
  fi
  echo "AWAY: $id ${view:-https://claude.ai/code/$id} base=$base branch=$br"
}

cmd="${1:-}"; [ $# -gt 0 ] && shift
```

```bash
cmd_land() {
  local base="${1:-}"; [ $# -gt 0 ] && shift
  local timeout=300 interval=10 take=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --timeout)  timeout="$2"; shift 2 ;;
      --interval) interval="$2"; shift 2 ;;
      --take)     take=1; shift ;;
      *) die 3 "usage: away land <base-sha> [--timeout S] [--interval S] [--take]" ;;
    esac
  done
  [ -n "$base" ] || die 3 "usage: away land <base-sha> [--timeout S] [--interval S] [--take]"
  to_root
  git cat-file -e "$base^{commit}" 2>/dev/null || die 3 "SKIP: $base is not a commit in this repository"
  local br; br=$(git symbolic-ref --short -q HEAD) || die 3 "SKIP: detached HEAD — switch to the branch you ran /away on"
  [ -z "$(git status --porcelain --untracked-files=no)" ] \
    || die 5 "DIVERGED: uncommitted changes here — commit them, then run /back again"

  local deadline=$(( $(date +%s) + timeout )) cand tip subj ref
  while :; do
    cand=""
    git fetch -q --prune origin '+refs/heads/claude/*:refs/remotes/origin/claude/*' 2>/dev/null
    for ref in $(git for-each-ref --sort=-committerdate --format='%(refname)' refs/remotes/origin/claude/); do
      git merge-base --is-ancestor "$base" "$ref" && { cand="$ref"; break; }
    done
    if [ -n "$cand" ]; then
      tip=$(git rev-parse "$cand"); subj=$(git log -1 --format=%s "$cand")
      [ "$subj" = "away: parked" ] || [ -n "$take" ] && break
    elif git log --format=%s "$base..HEAD" | grep -qx 'away: parked'; then
      echo "ALREADY LANDED: $br already holds the cloud's parked work ($(git rev-parse --short HEAD))"
      exit 0
    fi
    if [ "$(date +%s)" -ge "$deadline" ]; then
      if [ -n "$cand" ]; then
        echo "NOT PARKED: ${cand#refs/remotes/origin/} is at $(git rev-parse --short "$cand") \"$subj\" — the cloud is still working"
      else
        echo "NOT PARKED: no claude/* branch builds on $(git rev-parse --short "$base") yet"
      fi
      exit 4
    fi
    sleep "$interval"
  done
  local cbranch=${cand#refs/remotes/origin/}

  # Local commits since /away: code means someone worked here too — stop.
  # .continuity/-only ones (the board marker) are replayed on the cloud's tip.
  local c locals; locals=$(git rev-list --reverse "$base..HEAD")
  for c in $locals; do
    if git diff-tree --no-commit-id --name-only -r "$c" | grep -qv '^\.continuity/'; then
      echo "DIVERGED: this branch has code commits since /away — merge by hand. Cloud work is on $cbranch."
      git log --format='  cloud: %h %s' "$base..$tip"
      git log --format='  local: %h %s' "$base..HEAD"
      exit 5
    fi
  done
  local orig; orig=$(git rev-parse HEAD)
  git reset -q --keep "$tip" || die 1 "FAILED: could not move $br to $cbranch"
  for c in $locals; do
    if ! git cherry-pick -q "$c" >/dev/null 2>&1; then
      git cherry-pick --abort 2>/dev/null
      git reset -q --keep "$orig"
      die 5 "DIVERGED: local continuity commit $(git rev-parse --short "$c") conflicts with the cloud's changes (cherry-pick conflict) — nothing moved. Cloud work is on $cbranch."
    fi
  done

  git push -q origin "HEAD:refs/heads/$br" 2>/dev/null \
    || die 1 "FAILED: landed locally, but pushing $br was rejected — cloud work is on $cbranch"
  git push -q origin --delete "$cbranch" 2>/dev/null || echo "  NOTE: couldn't delete $cbranch on origin"
  echo "LANDED: $(git rev-list --count "$base..$tip") cloud commit(s) from $cbranch onto $br (now $(git rev-parse --short HEAD))"
  git log --reverse --format='  %h %s' "$base..$tip"
}
```
